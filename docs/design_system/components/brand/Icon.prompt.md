Lucide outline icon (1.75 px stroke, currentColor) from BitGauge's bundled glyph set — use for every UI glyph; never emoji.

```jsx
<Icon name="arrow-down" size={15} style={{ color: 'var(--series-download)' }} />
```

- `ICON_NAMES` lists every available glyph.
- Colour comes from the parent's `color`; direction icons use series tokens.
